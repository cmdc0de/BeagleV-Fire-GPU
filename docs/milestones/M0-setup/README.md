# M0. Laptop and board are set up

These guides are the step-by-step procedures for milestone M0. Follow them in order. `goals.md` is the procedure, `test.md` is the proof, and `implementation.md` is where this laptop and this board get recorded.

| Slice | Guide |
| --- | --- |
| S0.1 | [Laptop and FPGA IDE](slices/S0.1-laptop-and-ide/goals.md) |
| S0.2 | [Laptop project tools](slices/S0.2-laptop-project-tools/goals.md) |
| S0.3 | [Debian on the BeagleV-Fire](slices/S0.3-debian-on-the-board/goals.md) |
| S0.4 | [Prove boot and configure the board](slices/S0.4-prove-boot/goals.md) |
| S0.5 | [Program the FPGA from the Beagle](slices/S0.5-program-from-the-board/goals.md) |
| S0.6 | [Program the FPGA from the laptop](slices/S0.6-program-from-the-laptop/goals.md) |
| S0.7 | [Environment check script](slices/S0.7-check-env/goals.md) |

S0.6 needs a FlashPro programmer. The other slices do not. M0 is still complete when S0.6 is written and the programmer is absent, as long as S0.5 was run and S0.6’s `implementation.md` says the programmer was not attached.
